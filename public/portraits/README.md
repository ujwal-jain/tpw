# Portraits

Drop photographs here as `marcus.jpg`, `elena.jpg`, `david.jpg` (slugs come from
`PROFILES` in `src/app/page.tsx`). Portrait orientation, 4:5, at least 800×1000.

Until a file exists the card renders a flat panel with the subject's name — a
missing photo is better than a stock photo. Images render grayscale and warm to
full color on hover or keyboard focus.

Only use photographs you have a signed release for. These are composite
profiles, so do not pair them with an identifiable person's photograph without
that person's explicit consent to appear as an illustration.
